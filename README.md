# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；
以**硬时间/广告窗固定窗口**为锚点重算时长，支持突发插播、岗位权限、压缩/拒绝/撤回审计、
断网本地意图队列与主控版本对齐。

## 编排规则

- **固定窗口**：带硬时间的条目（含广告窗）是锚点。调整前面的节目后，系统以相邻锚点为界分段，
  在段内寻找可压缩段——只有**嘉宾、口播**可压缩，受最短时长（`minDuration`）保护；
  压缩从**最靠近固定窗口**的条目开始。硬时间自身、新闻片、连线、已播出条目、突发插播均不可压。
- **保不住就整次不生效**：可压缩段全部压到最短仍会挤掉广告窗或下一档硬时间时，
  本次调整完全不生效（串联单原样退回），并在冲突面板列出全部冲突条目（固定窗口 + 刚性条目 + 调整目标）。
- **突发插播**：可指定插在任意条目前/后；插播自身不参与压缩，会挤掉固定窗口时整次拒绝。
- **已播出条目**位置不可移动、时长不可调整。

## 断网与主控版本

- 所有改动都是带岗位与原因的**意图**。在线时先本地试算，通过后立即提交主控（主控持有单调版本号）。
- 断网期间意图进入本地 **FIFO 队列**，本地视图按操作先后重放（含预计压缩）用于应急播出。
- 主链路恢复后**逐条提交**：
  - 同一意图重复提交**只算一次**（主控幂等表去重）；
  - 主控版本已变化时，针对**最新主控重算这一条**，只退回真正冲突的那次；
  - 后面的本地意图不连坐，继续按最新顺序逐条重算。
- 队列页提供「模拟主控版本变化」按钮演示上述冲突退回与重算。

## 审计

被拒绝（含冲突条目）、被压缩（压缩前后时长）、被撤回（队列撤回 / 一键撤回还原）的操作，
都在审计台账中留下**岗位与原因**。
