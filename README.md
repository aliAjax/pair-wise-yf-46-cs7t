# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

源提示词摘要：面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；支持时长重算、硬时间风险、突发插播、角色权限、操作历史、一键撤回和断网应急队列。

## 技术栈

React19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next、date-fns、dnd-kit。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62011

## 核心机制

- **统一重算**（`src/store/recalc.ts`）：顺序、时长、硬时间、广告窗、突发插播都走同一个重算引擎。固定窗口被顶超时，从窗口向前按播出类型寻找可压缩段（口播/嘉宾可压，就近优先）；压到底仍保不住广告窗或硬时间时，本次调整不生效并指出冲突条目。
- **突发插播**：可插在指定条目前或后，重算时不会挤掉固定窗口。
- **断网应急队列**：离线编排先本地应用并入队；主链路恢复后按操作先后逐条提交，幂等键保证重复提交只算一次；主控版本已变化时只退回有冲突的那条，其余本地意图按主控最新顺序重算（队列页可"模拟主控变更"演示该路径）。
- **审计留痕**：被拒绝、被压缩、撤回的操作都记录岗位与原因，见"审计历史"页。
